# Slither AI

Исследовательский проект игрового ИИ для Slither.io-подобной среды. Цель — обучать агента с подкреплением в воспроизводимой локальной среде, оценивать прогресс и сохранять лучшие модели. Для официального Slither.io предусматривается отдельный визуальный помощник с рекомендациями; автоматическое управление официальным клиентом и обход его защит не входят в область проекта.

## Статус

**Phase 0 — проектная основа и MVP среды.** Репозиторий на момент старта оказался пустым; этот коммит создаёт документацию и начальный каркас. Реальное обучение ещё не подтверждено.

## Архитектура

- `slither_ai/envs` — локальная игровая среда и правила.
- `slither_ai/training` — обучение, оценка и сохранение checkpoints.
- `slither_ai/agents` — политики и обёртки агентов.
- `slither_ai/vision` — будущий анализ изображения официальной игры.
- `slither_ai/advisor` — будущие рекомендации игроку.
- `slither_ai/dashboard` — будущая панель наблюдения.
- `configs` — параметры экспериментов.
- `docs` — архитектура, решения, план, чеклист и handoff между сессиями.

## Быстрый старт

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -e ".[dev]"
python -m slither_ai.cli smoke
```

Для обучения на NVIDIA GPU установите PyTorch отдельно по официальной инструкции под вашу версию CUDA, затем установите проект. Не считайте наличие CUDA Toolkit достаточным: проверьте `torch.cuda.is_available()`.

```bash
python -m slither_ai.cli train --timesteps 100000
python -m slither_ai.cli evaluate --episodes 20
```

## Принципы разработки

1. Сначала корректная и тестируемая локальная среда, затем обучение.
2. Каждое улучшение подтверждается фиксированным evaluation-набором.
3. Лучший checkpoint не заменяется моделью без доказанного улучшения.
4. Конфигурация, метрики, seed и версия кода сохраняются для воспроизводимости.
5. Не внедрять обход антибота, протокольные манипуляции или автоматическое управление официальным клиентом.
