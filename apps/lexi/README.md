# Lexi

Локальное desktop-приложение для быстрого сохранения английских слов и фраз во время обучения и их повторения по простому интервальному расписанию.

## Что уже реализовано

- Быстрое создание карточки через кнопку или `Ctrl+K`.
- Поля: слово/фраза, перевод, тип, контекст и заметки.
- Локальная SQLite-база данных.
- Поиск по словам, переводам и контексту.
- Список карточек и удаление ненужных записей.
- Режим повторения: сначала вспомнить, затем открыть ответ; «Again» откладывает карточку на 10 минут, «Got it» — на 1 день.
- Статистика количества карточек и повторений.
- Тёмный минималистичный интерфейс.

## Требования к хосту

Для локальной сборки нужен только установленный Docker с Buildx. Node.js, npm, Rust, Cargo, Tauri CLI, компиляторы и Linux build-зависимости устанавливаются исключительно внутри контейнера.

## Сборка

Из корня репозитория:

```bash
bash apps/lexi/scripts/build.sh
```

Готовый файл: `apps/lexi/dist/Lexi.AppImage`.

## Запуск

```bash
bash apps/lexi/scripts/run.sh
```

Скрипт запускает AppImage с `--appimage-extract-and-run`, поэтому FUSE не требуется. Графическая сессия Linux должна быть доступна.

## Сборка без локального Docker

GitHub Actions автоматически собирает AppImage при изменениях в `apps/lexi/**` на ветке `feature/lexi-docker-foundation`. Готовый файл публикуется как artifact `Lexi-linux-x86_64-AppImage` на странице Actions соответствующего запуска (хранится 14 дней).

## Данные и переносимость

База хранится в стандартной пользовательской директории данных приложения; данные не отправляются в сеть.

AppImage собран на Ubuntu 22.04 для более широкой совместимости с Linux. AppImage не включает ядро Linux и glibc, а запуск зависит от совместимости системных библиотек и графического окружения. Сборка на Ubuntu 22.04 сама по себе не доказывает совместимость со всеми дистрибутивами; целевую систему необходимо проверить запуском.
