# Lexi

Локальное desktop-приложение для изучения английского через карточки и интервальное повторение.

Этот проект находится в отдельном каталоге `apps/lexi` и не меняет архитектуру Slither AI в корне репозитория.

## Требования к хосту

Для сборки требуется только Docker с BuildKit. Node.js, npm, Rust, Cargo, Tauri CLI и Linux build-зависимости устанавливаются исключительно в контейнере.

## Сборка

```bash
bash apps/lexi/scripts/build.sh
```

Результат появится в `apps/lexi/dist/`.

## Запуск

```bash
bash apps/lexi/scripts/run.sh
```

Скрипт запускает найденный AppImage. При первом запуске он делает файл исполняемым.

## Ограничения переносимости

AppImage не включает ядро Linux и glibc. Для совместимости с более старыми дистрибутивами сборка выполняется на Ubuntu 22.04 — базовой системе, совместимой с Tauri 2 и WebKitGTK 4.1. AppImage всё равно должен быть проверен на целевой Ubuntu 26.04; сборка сама по себе не доказывает runtime-совместимость.

На хосте не требуется устанавливать SDK или библиотеки разработки. Для запуска могут иметь значение системные ограничения AppImage, например FUSE; скрипт запуска использует `--appimage-extract-and-run` как запасной вариант.
